# X 粉丝数助手

在 X 用户昵称右侧显示粉丝数，所有粉丝数标签统一使用蓝色。

当前版本：**1.0.4**。

## 安装

1. 下载本仓库中的 `X粉丝数助手-v1.0.4.zip`，解压。
2. Chrome 地址栏输入 `chrome://extensions`，打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 `x-followers` 文件夹。
4. 刷新 X 页面。

旧版用户需要替换插件文件，在扩展管理页重新加载，再刷新 X。

## 功能

- 在昵称右侧显示简写粉丝数，鼠标悬停显示完整数量。
- 所有粉丝数标签统一配色，不按数量单独高亮。
- 支持读取新版 `relationship_counts.followers` 和旧版粉丝字段。
- 点击工具栏插件图标可查看响应、账号及标签数量，便于排查。

## 数据说明

不需要 API 密钥，不读取 Cookie，不上传数据，不发送额外查询。仅使用 X 页面已收到的用户数据，数量缓存在当前页面内存中。

没有粉丝字段的账号不显示数量。数据不是实时刷新；X 改动页面或接口后可能需要更新插件。
